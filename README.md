# null-inspect v0.1.0

Initial public release of null-inspect.

A lightweight JavaScript & TypeScript inspection toolkit for analyzing errors, logs, and stack traces through structured reports, root-cause detection, and actionable fixes.

---

# Features

- Error inspection
- Stack trace analysis
- Log analysis
- Confidence scoring
- Fix suggestions
- Structured inspection reports

---

# Public APIs

```
import {
    inspectError,
    inspectStack,
    inspectLogs,
} from "null-inspect";
```
